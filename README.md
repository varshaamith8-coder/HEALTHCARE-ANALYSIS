# Healthcare Data Analysis Using Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing healthcare data using Microsoft Excel. The workbook combines customer details, medical examination records, and hospitalisation information to organize health-related data, summarize important metrics, and present insights through PivotTables and a dashboard.

## 🎯 Project Objectives

- Organize and analyze healthcare and customer data.
- Use Excel formulas to calculate and categorize medical information.
- Combine information from multiple worksheets using lookup functions.
- Summarize health conditions using PivotTables.
- Create a dashboard for presenting key findings.
- Improve data analysis and reporting skills using Microsoft Excel.

## 🛠️ Tools and Techniques

- Microsoft Excel
- Excel Formulas and Functions
- IF and nested IF functions
- VLOOKUP and XLOOKUP
- MID, LEFT, FIND, and TRIM
- Data Categorization
- PivotTables
- Dashboard Creation
- Data Visualization

## 📂 Workbook Structure

The Excel workbook contains six worksheets:

### 1. Hospitalisation Details
Contains customer IDs, hospitalisation dates, date of birth, age, number of children, charges, hospital tier, city tier, and state ID.

### 2. Medical Examination Details
Includes BMI, weight status, HbA1c levels, diabetes status, heart issues, transplant history, cancer history, number of major surgeries, and smoking status.

### 3. Customer Names
Contains customer names and uses text functions to separate titles, first names, and last names.

### 4. Pivot Tables
Summarizes selected healthcare information using PivotTables to make data easier to analyze.

### 5. Dashboard
Provides a dashboard view for presenting summarized information from the healthcare dataset.

### 6. Health Care
Combines customer names, medical examination details, and hospitalisation information into a consolidated worksheet using lookup formulas.

## 📊 Key Analysis Activities

- **Data Organization:** Arrange customer and medical information across multiple worksheets.
- **Formula-Based Analysis:** Calculate age and categorize BMI and HbA1c values using Excel formulas.
- **Data Integration:** Retrieve related information from different worksheets using VLOOKUP and XLOOKUP.
- **Text Processing:** Extract customer titles, first names, and last names using text functions.
- **Data Summarization:** Use PivotTables to summarize selected health-related categories.
- **Dashboard Reporting:** Present summarized data in a dashboard for easier interpretation.
